# Radio Kashmir

Android radio app for stations from the Kashmir Valley only.

- **Live online:** Radio Kashmir Srinagar (Akashvani Srinagar), plus any stream you add in the app.
- **On FM in the Valley:** frequencies of local stations that have no internet stream.
- Plays in the background with notification and lock-screen controls.

## Get the APK

Every push to `main` builds the app with GitHub Actions and publishes it under
**Releases**. On your phone, open the latest release, download `RadioKashmir.apk` and install it.
